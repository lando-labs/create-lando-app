## The two artifacts (different lifetimes)

**1. Persistent brief** — read every session. Instructional, not a docs dump.
Canonical **`AGENTS.md`**; `CLAUDE.md` and the Cursor rule are thin pointers to it.

**2. Ephemeral bootstrap** — **`START_HERE.md`**, "burn after reading". First
session only: greet, confirm the MCP is live, orient to the getting-started page,
**then delete itself**. The persistent brief wires the read-then-delete.

| Tool | Rules/brief | Project MCP config | Notes |
| --- | --- | --- | --- |
| **Claude Code** | `CLAUDE.md` (auto-loaded) → points at `AGENTS.md` | `.mcp.json` (`mcpServers`) | agent at `.claude/agents/` (already shipping) |

**Correction to #12 as filed:** the issue claimed Codex MCP is global-only
(`~/.codex/config.toml`) and said to "document, don't fake it." That is **wrong** —
Codex supports per-project MCP via `.codex/config.toml`. All three tools get real
project-scoped MCP.

## Acceptance Criteria
- [ ] `AGENTS.md` authored as the single source — instructional, lean. Covers: stack,
      the MCP is wired, **use the `nextjs-lando-ds` agent**, discover components via
      MCP (don't assume APIs), #462 cascade rules, no Tailwind. Points at the DS's own
      `llms.txt` / `meta` as *reference*, not instructions.

      theme preset is set in `app/providers.tsx` — read it before any color decision;
      never hardcode hex, use DS tokens." A **rule, not a value** — so nothing needs
      syncing when the human changes the preset.
- [ ] `CLAUDE.md` = thin pointer to `AGENTS.md`.
- [ ] `.cursor/rules/lando-ds.mdc` = thin pointer, `alwaysApply: true`, **<200 words**.
- [ ] `START_HERE.md` bootstrap authored; the persistent brief wires read-then-delete.
- [ ] `.cursor/mcp.json` + `.codex/config.toml` generated from the same
      `MCP_SERVER_KEY` / `MCP_PACKAGE` constants as `.mcp.json` — no duplicated config.
- [ ] All AI files gated on the existing `mcp` flag (they travel together; `--no-mcp`
      yields a clean app with no AI wiring).
- [ ] Smoke test asserts the brief + pointers + all three MCP configs land.
- [ ] Nothing ships that a tool won't actually read (paths verified above).

### Packaging trap to respect
The repo `.npmignore` excludes `.claude/` — which is why the agent is vendored at
`templates/_shared/`. Dot-directories inside a template are a known hazard: the
Cursor rule follows the same `_shared/` + copy-at-scaffold pattern rather than
living at `templates/<t>/.cursor/`. **Verify with `npm pack --dry-run` that every
new file actually ships.**
