**1. Persistent brief** — read every session. Instructional, not a docs dump.

new file actually ships.**

### What verification caught
- **#12's own premise was wrong.** It claimed Codex MCP is global-only and said to
  "document, don't fake it." Codex supports per-project MCP via `.codex/config.toml`.
  Checking the docs *before* authoring turned an apology into a feature.
- **Codex's key is `mcp_servers`, not `mcpServers`.** camelCase yields a file Codex
  silently ignores — no error, just an inert config in every scaffolded project.
- **Cursor bills always-apply rules on every request** (<200 words recommended),
  which independently validated the thin-pointer design rather than duplicating
  the brief per tool.
- All five new files confirmed present in `npm pack` — the `.npmignore` `.claude/`
  trap that nearly ate the agent applies to every dot-path we add.

### Lessons Learned
- This layer is **entirely silent-failure surface**: every artifact is a file some
  tool may or may not read, and being wrong looks identical to being right. That's
  why the guard asserts shapes and cross-tool agreement, and why it was
  negative-tested (camelCase key → correct failure naming the cause).
- The IA insight held up in implementation: the brief carries a **rule, not a
  value**, so the human→AI theme loop needs no syncing mechanism at all.
