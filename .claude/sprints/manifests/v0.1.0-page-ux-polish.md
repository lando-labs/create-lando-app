## Acceptance Criteria (the audit's 6 fixes, ranked)
**#1 — Collapse the harmony control [HIGH · the biggest lever]**
- [ ] The 3 ramp chips **and** the pin-secondary switch move behind an optional
  disclosure ("Customise secondary + accent", default **closed**; `useDisclosure`
  already imported). Default ramp stays `tonal`.
- [ ] Default §1 view is a single path: primary well/hex → AA badge → quick-starts
  → live components → copy. The colour **engine is untouched**.

**#2 — Fix "nothing happened" / swatch billing [HIGH]**
- [ ] Lead with `primary` as the hero on the real Button; don't give secondary/accent
  co-equal visual weight in the default frame.
- [ ] Print the **resolved hex under each swatch** so sameness/difference is legible.
- [ ] When the harmony disclosure is open, label secondary/accent as **derived
  supporting roles you consume manually** (so identical-looking swatches read as
  intentional). Do NOT fake secondary/accent onto a stock component — the DS keeps
  those variants neutral by design.

**#3 — Make §1→§2 one motion [MED]**
- [ ] Replace the anonymous divider with a connective line after the CodeBlock
  (artifact → hand-off), and number the two beats (1 / 2) so they read as a sequence.

**#4 — Operationalize the hand-off [MED]**
- [ ] Starter prompts become **copyable** rows (reuse the existing copy pattern).
- [ ] One explicit mechanic line above them: open this folder in Claude Code / Cursor
  — `.mcp.json` + the `nextjs-lando-ds` agent are already wired — paste one.

**#5 — Warm the header [LOW]**
- [ ] Keep the mono status line, add one plain-language purpose sentence; front-load
  the "this page is meant to be deleted" contract (currently only in the footer).

**#6 — Close the contrast perception gap [LOW–MED]**
- [ ] When a colour was contrast-corrected, the emitted CSS must not silently differ
  from the visible input — either reflect the corrected value into the hex field, or
  caption the CodeBlock ("emitted with the contrast-safe value #…, not #…"). Keep the
  DS red and the correction maths exactly as-is.

**Cheap win**
- [ ] If the harmony control survives (behind the disclosure), the **visible** ramp
  labels use the plain-language phrasing ("Shades of your one colour", "Colours next
  to yours", "A contrasting pop for accents"), not the jargon Tonal/Neighbouring/Opposite.

- [ ] Smoke test green (the page invariants still hold — presets gone, engine wired,
