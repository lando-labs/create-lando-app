## Full Issue Details

> Hydrated on: 2026-07-12 · Source: GitHub Issues (lando-labs/create-lando-app)

### Issue #1: Build the consumer smoke test (`scripts/smoke.ts`)
**Labels**: `blocked:a1`, `ci-cd` · **State**: Open

The real guard for the #462 cascade-layer contract. A plain `DS_VERSION` bump
can't catch a layer-contract break — only a build-and-assert can.

**What it does**
1. Scaffold the `next-app-router` template into a temp dir (reuse the CLI's copy
   + placeholder-substitution path).
2. `npm install` against the target DS version (or a local DS tarball in CI).
3. `next build`.
4. Assert DS component spacing survives the `@layer app-reset` reset (the #462
   invariant) — e.g. computed padding/margin on a rendered DS component is
   non-zero.

**Wiring**: replace the `npm test` placeholder; CI runs it on PR/push; drafted
**dormant** now (skips cleanly when the DS can't be resolved), flipped live at A1.

### Issue #2: Wire DS→CLI drift auto-PR (repository_dispatch receiver)
**Labels**: `blocked:a1`, `ci-cd` · **State**: Open

Keep templates in sync with the DS layer contract via **CI push, not pull**.

**Receiver side (this repo)**: a workflow triggered by `repository_dispatch`
(type `ds-published`) that bumps `DS_VERSION` in `src/index.ts`, opens a PR, and
the PR runs the consumer smoke test (#1) as the real drift guard.

**Dispatcher side (DS repo — sibling half)**: the DS `publish.yml` adds a
`repository_dispatch` step targeting this repo on release. Out of scope here.

### Build order (dependency)
#2 depends on #1 (the drift PR's value is that it runs the smoke test). Build the
shared scaffold module → smoke test → drift workflow.

### Deviations from plan (intentional)
- Smoke test is `scripts/smoke.mjs`, not `.ts` — plain ESM runs on the CI's
  Node 20 with zero toolchain, and importing `dist/scaffold.js` means it tests
  the **compiled artifact that actually ships**.
- `DS_VERSION` moved from `src/index.ts` → `src/scaffold.ts` (the extracted
  shared module). The drift workflow patches the new location. Docs (CLAUDE.md)
  still say "top of src/index.ts" — **follow-up:** update that reference.

### Lessons Learned
- Running the live smoke path locally (via the on-disk DS tarball) caught two
  real bugs a dormant-only test would have shipped: (1) the layer-order regex
  matched `@layer` inside a CSS comment; (2) the workflow's verify `grep` broke
  on regex metacharacters in version strings (fixed with `grep -F`).
- The entire A1-gated flow is **already proven locally** — launch (Sprint 2)
  is de-risked far more than the plan assumed.
