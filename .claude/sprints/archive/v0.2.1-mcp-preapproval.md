## The problem
Every call to the `lando-ds` MCP hits a permission prompt in Claude Code, breaking
the "just talk to your AI" flow the scaffold sells. Claude Code supports
pre-approving MCP tools via a committed `.claude/settings.json` — gated by the
workspace-trust dialog, so it's safe and transparent (the user still approves
trusting the project).

## Decision (owner, 2026-08-12)
**On by default when Claude is wired.** With #24's `--ai` flag in place, the
pre-approval rides along with the `claude` selection — no separate flag. `--ai none`
(and any selection without `claude`) writes nothing.
