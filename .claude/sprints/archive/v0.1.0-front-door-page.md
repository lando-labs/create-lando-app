## The design (from the IA spec, `app-information-architect`)

> "This page is not an announcement, it's a control panel for the two things a
> fresh scaffold actually lets you change — the theme preset, and the AI brief."

It renders at `localhost:7711` **inside the user's own new codebase**. It is
disposable by design; its success condition is its own deletion.

## Acceptance Criteria

**Palette (#13)**
- [ ] Swatch grid: rows = color family, cells = ramp steps.
- [ ] **Fill from the CSS custom property; label from the JS token export. The page
      never holds a hex string.** (JS values would lie the moment the theme toggles —
      only `var(--…)` stays honest across preset + light/dark.)
- [ ] Click-to-copy copies the **token path, not the hex** — don't build the
      affordance for the failure mode the DS exists to prevent.
- [ ] Theme toggle (top-right, above the palette it controls).

**Preset chooser (#13)**
- [ ] Offers only the **3 accessible presets**: `brand-neutral` (6.00), `lando`
      (4.52), `slate` (4.76). The other 4 fail WCAG AA — see
      lando-labs/lando-labs-design-system#542. Re-add when fixed.
- [ ] **"The page proposes, the file disposes."** The chooser previews; its *output*
      is a copyable diff, not runtime state a refresh would lose.
- [ ] Emits **two edits that must agree** (or the app flashes the wrong palette):
      `app/providers.tsx` → `<ThemeProvider preset="…">` **and** `app/layout.tsx` →
      `themeScript({ defaultPreset: '…' })`.
- [ ] `providers.tsx` gains the `preset` prop as the single theme source of truth.

**Onboarding (#14)**
- [ ] "How to talk to your AI" — copyable starter prompts, accurate to the shipped
      agent + DS.
- [ ] "What your AI already knows" — **rendered from `AGENTS.md`**, not hand-copied.
      One brief, two renderings, unable to drift. This mirror *is* the teaching device.
- [ ] File map (5 rows), one line each, links out for depth.
- [ ] Explicit exit line.

**Constraints**
- [ ] RSC by default; `'use client'` only for the interactive bits.
- [ ] DS components via deep subpath imports; **no Tailwind**; tokens only.
- [ ] #462 wiring + `themeScript()`/`ThemeProvider` semantics untouched.
